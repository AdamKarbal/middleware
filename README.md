Let's Go Biking ! 🚲



🛠️ Prérequis

Apache ActiveMQ doit être installé et lancé sur votre machine avant de démarrer le projet.

Visual Studio 2022

📦 Installation (A faire si on clone depuis le GitHub, si .zip, passer à la prochaine étape)

Ouvrez le fichier Projet.sln avec Visual Studio.

Dans le menu en haut, cliquez sur Générer > Générer la solution (ou Ctrl + Shift + B).

🚀 Lancement du projet

Rendez-vous dans le dossier racine : Middleware/Projet.

Faites un clic-droit sur le fichier start.bat.

Choisissez "Exécuter en tant qu'administrateur" (recommandé pour éviter les blocages de ports).

Note : 5 fenêtres de console vont s'ouvrir. Ne les fermez pas tant que vous utilisez l'application.

📱 Utilisation

1. Site Web

Le navigateur s'ouvrira automatiquement sur la carte (http://localhost:8080/page2.html). Entrez vos adresses pour calculer un itinéraire multimodal (Marche + Vélo).

2. Client Lourd (Console)

Une des fenêtres noires ouvertes est le Client Lourd.

Il suffit d'écrire l'adresse de départ et d'arrivée lorsque demandé.

Pour quitter le client lourd, tapez simplement stop comme adresse de départ.
