🚴‍♂️ Projet Middleware – GPS Vélo Partagé

Ce projet vise à développer une architecture complète de services distribués permettant le calcul d’itinéraires intelligents combinant la marche et le vélo, grâce aux données JCDecaux et OpenRouteService.

🧠 Architecture du projet

  • ServerGPS (REST + SOAP) : gère les calculs d’itinéraires et interagit avec les APIs externes.
  • ProxyCache (SOAP) : met en cache les réponses des APIs pour éviter les appels répétés et améliorer les performances.
  • Serveur Lourd : utilise ServerGPS
  • ActiveMQ : Notifications météo, trafic et pollution
