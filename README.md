Let's Go Biking ! 

Prérequis

Apache ActiveMQ doit être installé et lancé sur votre machine avant de démarrer le projet.

Lancement 

Nous avons automatisé le lancement de tous les serveurs (Proxy, GPS, Notifications, Web) et des clients.

Rendez-vous dans le dossier : Middleware/Projet.

Faites un clic-droit sur le fichier start.bat .

Choisissez "Exécuter en tant qu'administrateur".

Note : 5 fenêtres de console vont s'ouvrir. Ne les fermez pas tant que vous utilisez l'application.

📱 Utilisation

1. Site Web

Le navigateur s'ouvrira automatiquement sur la carte (http://localhost:8080/page2.html). Entrez vos adresses pour calculer un itinéraire.

2. Client Lourd (Console)

Une des fenêtres noires ouvertes est le Client Lourd.

Il suffit d'écrire l'adresse de départ et d'arrivée lorsque demandé.
